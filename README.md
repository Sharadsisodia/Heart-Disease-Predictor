# 🫀 Heart Disease Prediction System

**From Code to Care: Predicting Heart Disease with Tech**

This project is a Machine Learning-powered web application designed to assess the risk of heart disease based on patient data. Built with a focus on accessibility and real-world impact, the system helps users get instant insights into their heart health.

🔗 **Live Demo**: [heart-disease-predictor-n0bw.onrender.com](https://heart-disease-predictor-n0bw.onrender.com/)  
📁 **GitHub Repo**: [github.com/Sharadsisodia/Heart-Disease-Predictor](https://github.com/Sharadsisodia/Heart-Disease-Predictor)

---

## 🚀 Features

- 🔍 Predicts risk of heart disease using ML models
- 🧠 Supports Logistic Regression & Linear Regression
- 🌐 Clean, user-friendly web interface
- 🗃️ Secure form-based data input
- 📊 Immediate results with insights

---

## 💻 Tech Stack

- **Frontend**: HTML, CSS, Bootstrap
- **Backend**: Django (Python)
- **ML Models**: Logistic Regression, Linear Regression (Scikit-learn)
- **Deployment**: Render

---

## 🛠️ How It Works

1. User enters medical and lifestyle data into a form.
2. Data is preprocessed and sent to the ML model.
3. Model predicts the probability of heart disease.
4. Prediction is displayed clearly on the results page.
